tesrig_api · dependency-free

Process OpenFOAM results with Python

TesRig supplies the interpreter, case context, field readers, airflow helpers, and versioned result writers. Import only what your script needs.

Quick start

from tesrig_api import latest_snapshot, write_result

snapshot = latest_snapshot()
write_result("summary", {
    "time": snapshot["time"],
    "mean_speed": snapshot["velocity_magnitude"]["mean"],
    "mean_pressure": snapshot["pressure_statistics"]["mean"],
})

Scripts are stored with the simulation case. Valid edits are autosaved, and the Run action executes them using TesRig's packaged Python runtime.

Case and result times

case_directory() -> pathlib.PathAbsolute path to the current OpenFOAM case.
time_directories() -> list[tuple[float, Path]]Numeric result directories in ascending order.
latest_time() -> tuple[float, Path]The newest available result time and directory.
available_fields(time=None) -> list[str]Field files available for a selected or latest time.

Reading fields

read_field(field, time=None, limit=None) -> listRead an ASCII scalar or vector internalField. read_internal_field is the explicit alias.
latest_snapshot(limit=10000) -> dictRead sampled velocity and pressure plus speed and pressure statistics. 
from tesrig_api import available_fields, latest_time, read_field

time, _ = latest_time()
print(available_fields(time))
velocity = read_field("U", time, limit=5000)
pressure = read_field("p", time, limit=5000)

The built-in reader supports OpenFOAM ASCII uniform and nonuniform scalar/vector internal fields. Binary field decoding and OpenFOAM post-processing functions are intentionally outside API 1.0.

Flow helpers

vector_magnitude(value) -> floatEuclidean magnitude for a vector iterable.
field_statistics(values) -> dictMinimum, maximum, and arithmetic mean.
sample_every(values, step, limit=None) -> listUniformly thin a large field before writing output.
dynamic_pressure(speed, density=1.225) -> floatDynamic pressure in Pa.
pressure_coefficient(pressure, reference_pressure, speed, density=1.225) -> floatDimensionless pressure coefficient Cp.

Writing results

write_result(name, data, *, kind="data", metadata=None) -> PathWrite any JSON-compatible value in TesRig's versioned result envelope.
write_probe(name, points, values, *, units="", metadata=None) -> PathWrite points and scalar/vector samples as a probe result.
write_table(name, columns, *, units=None, metadata=None) -> PathWrite equal-length named columns as a table result.
Output Location Kind
write_result tesrig-processing/results/<name>.json Custom
write_probe Same results directory probe
write_table Same results directory table

Examples

Pressure coefficient table

from tesrig_api import read_field, pressure_coefficient, write_table

pressure = read_field("p", limit=2000)
cp = [pressure_coefficient(value, 0.0, speed=10.0) for value in pressure]
write_table("pressure_coefficient", {
    "sample": range(len(cp)),
    "pressure": pressure,
    "cp": cp,
}, units={"pressure": "Pa", "cp": "1"})

Sampled velocity probe

from tesrig_api import read_field, sample_every, write_probe

velocity = sample_every(read_field("U"), step=10, limit=500)
points = [[index, 0.0, 0.0] for index in range(len(velocity))]
write_probe("sampled_velocity", points, velocity, units="m/s")

Execution model

  • Syntax checking uses Python's AST parser and never executes the script.
  • Run uses the Python runtime packaged with TesRig; a system Python installation is not required.
  • TESRIG_CASE_DIR is assigned by TesRig for each run.
  • The API is dependency-free. Third-party packages are not bundled in API 1.0.
  • Scripts run with the user's permissions and should be treated as executable code.
